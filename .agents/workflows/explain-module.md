# Explain a module

Ask me which module (core/eligibility.py, core/documents.py, services/copilot.py, ui/shell.py, services/monitoring.py ...). Then:
1. Explain what it does and WHY it exists, using real function names, in plain words.
2. Give a 60-second spoken explanation I can say to a jury.
3. List 5 hard questions a jury could ask about it and answer each from the code (cite file + function).
4. Ask me 3 questions back to check I understood. Do not change any code.
